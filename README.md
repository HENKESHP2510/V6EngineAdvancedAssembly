# V6EngineAdvancedAssembly
This CAD model features a detailed 6-cylinder V-engine assembly (V6 ENGINE ASSEMBLY.SLDASM) rendered in SolidWorks with partially transparent outer housings to highlight its internal mechanical sub-assemblies.The V-bank block layout accommodates six reciprocating pistons connected to the central crankshaft mechanism, with dual front-mounted conical air filters feeding into a custom intake manifold overhead. The valve train displays dual overhead camshafts (DOHC) driving the rocker arm assemblies, valve springs, and engine valves within each cylinder head. The lower assembly integrates the crankcase, oil pan, front timing gear covers, belt pulley system, and side-routed exhaust manifolds for optimized spatial packaging.
